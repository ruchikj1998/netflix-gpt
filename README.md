# Netflix-GPT

Netflix-GPT is a movie browsing and recommendation platform powered by TMDB API and OpenAI's GPT. It provides personalized movie suggestions and trailers with an AI-driven search experience.

https://netflix-6uuisolij-ruchiks-projects.vercel.app/

## Features

### Authentication
- User authentication using Firebase
- Signup and login functionality
- Redirect users to the browse page after authentication

### Movie Browsing
- Display trending movies with background trailers
- Show movie titles, descriptions, and suggestions
- Categorized movie lists (popular, upcoming, etc.)
- Movie cards with detailed information

### AI-Powered Search
- GPT-powered search functionality
- Multi-language search support
- AI-generated movie recommendations based on search queries
- Integration with TMDB API for fetching relevant movies

### Additional Features
- Custom hooks for fetching and managing API data
- Redux for state management
- Memoization for optimized performance
- Secure API keys with an environment file

## Configuration & Setup

### Prerequisites
- Node.js installed
- Firebase account set up
- TMDB API key
- OpenAI API key

## Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **State Management:** Redux
- **Backend Services:** Firebase Authentication
- **APIs:** TMDB API, OpenAI GPT API
- **Hosting:** Firebase Hosting
